# HeliBoard

HeliBoard is a GPL-3.0 privacy-conscious keyboard derived from OpenBoard and AOSP LatinIME. The reference clone is `repos/heliboard` from `https://github.com/HeliBorg/HeliBoard`.

It provides mature offline dictionaries, custom text-file layouts, multilingual typing, clipboard history, split and one-handed modes, and extensive inherited LatinIME touch infrastructure. Its architecture is useful as a conservative reference for Android input-connection behavior and dictionary integration.

HeliBoard's current glide typing depends on an externally loaded closed-source `swypelib` and is not shipped in the app. It does not provide Unexpected-style eight-direction values on every key or FlorisBoard's general board-wide swipe-action bindings. It is therefore a supporting compatibility reference rather than the shortest base for the proposed personal keyboard.

See [FUTO Keyboard](../android-keyboard/summary.md), [Unexpected Keyboard](../unexpected-keyboard/summary.md), and [FlorisBoard](../florisboard/summary.md).
